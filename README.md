# MMA: Road to UFC

Career RPG about climbing from regional MMA to the UFC.

- 10 major real-world organizations with division rankings and P4P.
- 6 regional organizations without rankings.
- Fighter creation, styles, attributes, contracts, money, popularity.
- Round-by-round fight mode.
- Career history and local save via browser localStorage.

Open `index.html` directly or enable GitHub Pages for the repository.
